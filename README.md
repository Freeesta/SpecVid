# SpecVid

Physics models and [Manim](https://www.manim.community/) animations for teaching
LC-UV → ESI → triple quadrupole / QTRAP (environmental chemistry MSc course).
Language of the videos: English. Equations are shown on screen.

## Layout

```
core/        physics only (numpy/scipy), no graphics, unit-tested
  quad/      Mathieu stability, scan line, ion trajectories
  msms/      ion library, CID branching model, full scan / product ion / MRM spectra
  lc/        chromatographic peak shapes (more to come)
scenes/      one Manim scene per teaching concept (style.py = shared look)
tests/       pytest
```

Planned modules: `core/esi`, `core/uv`, fuller `core/lc` (gradient, van Deemter).

## Render

```bash
manim -pql scenes/quad_stability.py    QuadStability     # draft 480p15
manim -qh  scenes/quad_trajectories.py QuadTrajectories  # final 1080p60 for YouTube
manim -ql  scenes/qqq_scans.py FullScan          # also: ProductIonScan, MRM
```

## Scan-mode scenes (`scenes/qqq_scans.py`)

One consistent story with three triazines (simazine 202, atrazine 216, terbuthylazine 230)
and an invented isobaric matrix ion at m/z 216:

1. **FullScan**: Q1 scans, Q2/Q3 RF-only. The 216 peak is two ions but looks like one.
2. **ProductIonScan**: Q1 fixed at 216, CID in Q2, Q3 scans. Two fragment families appear;
   then a collision-energy ramp and breakdown curves.
3. **MRM**: Q1 and Q3 fixed (216 → 174) rejects the interferent; then the three transitions
   are cycled while the compounds elute in an LC run.

The ion stream and the spectra are generated by the same model (`core/msms`).

Output goes to `media/` (git-ignored).

## Conventions

- Mathieu form: `u'' + (a_u - 2 q_u cos 2ξ) u = 0`, `ξ = Ωt/2`,
  `a = 8zeU/(m r0² Ω²)`, `q = 4zeV/(m r0² Ω²)`. The sign of q only shifts the RF phase.
- Trajectories use a circular approximation of the rod surface (`r = r0`) and ~13 RF
  cycles; real instruments need hundreds of cycles to traverse the filter.
- **Fragment channels, abundances, collision energies and retention times in the scan-mode
  scenes are illustrative teaching numbers, not measured data** (the videos say so on screen).
  Mass-filter windows in the ion stream are exaggerated for visibility. Optimise real
  transitions on the 3200 QTRAP with standards.
- Instrument parameters (RF frequency, r0, voltage ranges) for the 3200 QTRAP are
  **not** hard-coded: take them from the Sciex manual before showing absolute m/z values.
